# Sistem Skrining Diagnosis Tingkat Risiko Kehamilan

Project skripsi menggunakan Django dan MySQL.

## Teknologi

- Python
- Django
- MySQL
- XAMPP
- Bootstrap

## Cara Menjalankan

1. Install Python
2. Install dependency

```
pip install -r requirements.txt
```

3. Import database MySQL
4. Jalankan

```
python manage.py runserver
```
